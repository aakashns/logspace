# LogSpace has moved

LogSpace now lives in [aakashns/aak.sh](https://github.com/aakashns/aak.sh/tree/main/logspace).
Visit [logspace.aak.sh](https://logspace.aak.sh) for the demo and installation instructions.

- **Install:** `curl -fsSL https://logspace.aak.sh/install.sh | sh`
- **Already installed?** Run `logspace upgrade`. Versions through 0.7.24 upgrade to
  [0.7.25](https://github.com/aakashns/logspace/releases/tag/v0.7.25) from this repo. The
  0.7.25 binary and later versions check for updates in aak.sh.
- **Releases:** Older downloads stay in [this repository](https://github.com/aakashns/logspace/releases).
  New releases use `logspace-v*` tags in [aak.sh](https://github.com/aakashns/aak.sh/releases?q=logspace-v&expanded=true).

Open new issues and pull requests in [aakashns/aak.sh](https://github.com/aakashns/aak.sh).
